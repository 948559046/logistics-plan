# logistics-plan 智能跨境物流解决方案
> Intelligent Logistics Solution｜跨境装箱模拟、体积重计费、海外地址校验一体化系统

## 介绍
用户选购商品进入结算时触发。这套**智能物流系统**基于商品尺寸重量、已启用箱规、已启用物流渠道，自动生成装箱方案，匹配符合条件的物流渠道，算出对应运费，并返回给前端展示可选渠道，是一套实用的**跨境物流方案**。

用户不需要理解箱规、体积重、首重续重等概念，只需要看到“有几箱、走哪些渠道、每个渠道多少钱、多久能到”。**物流体积重计算、自动分箱拆分**这些复杂逻辑全部由系统完成，用户端只展示业务结果和必要的提示。

## 软件架构
软件架构说明 后端：Java / SpringBoot 前端：Vue

能力：**装箱算法**、体积重计算、物流渠道报价、地址校验

### 核心能力：
✅ 地址校验：海外收货地址标准化校验，**国际地址校验**<br>
✅ 装箱模拟：3D可视化装箱预览，空间优化，**包裹装箱优化**<br>
✅ 费用预估：实重/体积重自动比对计费，支持多包裹拆分，快速核算**跨境物流成本**<br>
✅ 多渠道：对接多条跨境物流线路，时效、运费自动展示，适合**货代报价**

## 🎯 适用场景
跨境独立站、外贸电商、货代企业、跨境卖家，用于下单前预核算物流成本、提前模拟装箱，可作为**货代系统、独立站运费预估工具**。

## English Introduction
logistics-plan is an intelligent cross border logistics system. It supports carton packing simulation, dimensional weight calculation, freight quotation and international address validation.

When customers checkout, the system automatically generates packing plans, selects available logistics channels and calculates shipping cost. Ecommerce merchants and freight forwarders can use it to estimate cross border freight and optimize parcel packing.

Core features:
- International address validation
- 3D packing preview & carton optimization
- Dimensional weight calculator
- Multi-carrier freight estimate
- Automatic shipment split algorithm
